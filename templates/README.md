# MdTex テンプレートパック

このフォルダには、MdTex プラグインの **defaults 方式**（文書テンプレート方式 = `defaults`）で使う
**テンプレートパック** のサンプル集とガイドを収録しています。

- **既存のパックを選んで PDF に出す方法** → このファイル
- **新しいテンプレートパックを自作する方法** → [SKILL.md](./SKILL.md)

---

## 使い方

### 1. パックを vault へ置く

使いたいパックのフォルダ（例: `縦書き二段組/`）を、Obsidian vault の
テンプレートフォルダ（既定: `MdTex Templates/`）へコピーします。

```
<vault>/MdTex Templates/
└── 縦書き二段組/        ← ここへフォルダごとコピー
    ├── defaults.yaml    ← ★必須: パックの入口
    ├── tate-twocolumn.tex
    ├── preamble.tex
    └── aozora-ruby.lua
```

> このフォルダは vault の中にあるため、Obsidian Sync / Git で同期・バックアップされ、
> **プラグインの更新でも消えません**。

プラグインの初回起動時にも、サンプルパック（縦書き二段組・情報系論文風）が自動展開
されます。手動で追加・差し替えたい場合だけこの GitHub のパックを使ってください。

### 2. MdTex の設定で選ぶ

1. MdTex 設定 → 対象プロファイルの「文書テンプレート方式」を **defaults file** に
2. 「defaults file の指定方法」を **テンプレートパックから選択** に
3. 「テンプレートパック」の横の **再スキャン** を押す
4. ドロップダウンから使いたいパックを選ぶ
5. Markdown 本文を開いて PDF 変換を実行

本文（`.md`）は通常の Markdown です。defaults 方式でも MdTex 固有の機能
（Obsidian 記法・callout・Mermaid・相互参照など）はそのまま使えます。

## テンプレートパックの構造

テンプレートパックは、**`defaults.yaml` を含むフォルダ** です。
1 つのフォルダがそのまま 1 つの文書テンプレートになります。

```
MdTex Templates/
└── <パック名>/                ← フォルダ名 = ドロップダウンに表示される名前
    ├── defaults.yaml          ← ★必須: Pandoc defaults file（パックの入口）
    ├── <name>.tex             ←    任意: カスタム Pandoc テンプレート
    ├── preamble.tex           ←    任意: プリアンブル（\usepackage 等）
    └── <name>.lua             ←    任意: Lua フィルタ（記法拡張）
```

- **必須ファイルは `defaults.yaml` だけ**です。これが含まれるフォルダだけが
  ドロップダウンに現れます。
- 補助ファイルは同じフォルダに置き、`${.}`（defaults.yaml 自身のディレクトリ）で参照します。
  これでパック全体をフォルダ単位でコピー・Git 管理できます。

---

## 新しいパックを追加するには

1. テンプレートフォルダ（`MdTex Templates/`）の直下に、テンプレート名と同じフォルダを作る
   （フォルダ名がドロップダウンに表示される名前になります）
2. その中に `defaults.yaml` を置く（最小はこれだけで認識されます）
3. 設定で **再スキャン** を押す

詳しい作り方・検証手順・よくある落とし穴は **[SKILL.md](./SKILL.md)** を参照してください。

## 収録サンプル

| パック | 用途 |
|---|---|
| `縦書き二段組` | 縦書き小説（ルビ・圏点付き）。青空文庫風ルビ記法 `｜親文字《よみ》` を LaTeX の `\ruby` に変換する Lua フィルタ同梱。 |
| `情報系論文風` | 情報処理学会・人工知能学会風の二段組論文。和文タイトル・概要・キーワード・表・数式・コード。 |

> ⚠️ **注意**: これらのサンプルは実在学会の公式テンプレートではなく、見た目を再現した
> 汎用サンプルです。公式テンプレートが配布されている学会へ投稿する場合は、その学会が
> 指定する LaTeX クラス・スタイルファイルを使ってください。

サンプルパックの中身を読むのが、構造を知る一番の近道です。
