# 国際化（i18n）ガイド

[ドキュメントインデックス](./index.md) > 国際化（i18n）ガイド

## 概要

このガイドでは、MdTeXプラグインの国際化の追加と保守について説明する。現在、英語と日本語をサポートしている。

### 目的

i18nシステムにより、プラグインは複数の言語でUI文字列を表示できる。

### 設計目標

- 型安全な翻訳キー
- 新しい言語の追加が容易
- 欠けている翻訳は英語にフォールバック
- 最小限のランタイムオーバーヘッド

---

## アーキテクチャ

### ファイル構造

```
src/lang/
├── helpers.ts           # 翻訳ヘルパー関数
└── locale/
    ├── en.ts            # 英語翻訳（ベース）
    └── ja.ts            # 日本語翻訳
```

### 型定義

**ファイル**: `src/lang/locale/en.ts`

```typescript
export type TranslationKeys =
  | "ribbon_convert_active"
  | "cmd_convert_pdf"
  | "setting_output_format_name"
  // ... 他のすべてのキー;
```

`TranslationKeys`型はすべてのロケールファイルで共有され、型安全性を確保する。

## 翻訳の追加

### 新しいキーの追加

1. `src/lang/locale/en.ts`にキーを追加：

```typescript
export const en: Record<TranslationKeys, string> = {
  // 既存のキー...
  "new_key": "New English translation",
};
```

2. `src/lang/locale/ja.ts`に翻訳を追加：

```typescript
export const ja: Record<TranslationKeys, string> = {
  // 既存のキー...
  "new_key": "新しい日本語訳",
};
```

---

## コードでの翻訳の使用

### 翻訳関数

```typescript
import { t } from "./lang/helpers";

const message = t("setting_output_format_name");
```

### パラメータ付き翻訳

パラメータが必要な翻訳の処理は手動で行います：

```typescript
const fileName = "test.md";
const message = `Converting ${fileName}...`;
```

---

## 新しい言語の追加

### 手順

1. 新しいロケールファイルを作成: `src/lang/locale/fr.ts`

2. `TranslationKeys`型を拡張

3. 翻訳を実装

4. `helpers.ts`に新しいロケールを登録

```typescript
import fr from "./locale/fr";

const translations: Record<Locale, Record<TranslationKeys, string>> = {
  en,
  ja,
  fr, // 新しい言語
};
```

---

## ロケールの検出

ロケールはObsidianの`moment.locale()`に基づいて決定されます：

```typescript
const locale = moment.locale();
const lang = locale.startsWith("ja") ? "ja" : "en";
```

## 翻訳のテスト

### 翻訳が存在することを確認

```typescript
describe("翻訳", () => {
  it("すべてのキーが翻訳されている", () => {
    const keys = Object.keys(en) as TranslationKeys[];
    keys.forEach(key => {
      expect(t(key)).toBeDefined();
    });
  });
});
```

## 翻訳キーの規約

### 命名規則

- 小文字とアンダースコアを使用
- 階層的命名: `category_specific_name`
- 例: `cmd_convert_pdf`、`setting_output_format_name`

### カテゴリ

| プレフィックス | 用途 |
|--------------|------|
| `cmd_` | コマンド名 |
| `setting_` | 設定項目 |
| `ribbon_` | リボンのツールチップ |
| `status_` | ステータスバーメッセージ |
